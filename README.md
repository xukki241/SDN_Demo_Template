# Hai bản template Slot 10

Trong thư mục này chỉ giữ hai bản giống nhau để dùng một bản và dự phòng một bản:

- [Template-Slot10](Template-Slot10/README.md)
- [Template-Slot10-Backup](Template-Slot10-Backup/README.md)

Cả hai đều là một project độc lập React Bootstrap + Express + Mongoose, làm với `students`, theo response contract `{ success, data, message }` trong slide. Backend giữ khung route và `server.listen`; các phần cần live code để TODO. Frontend là form/bảng Bootstrap và vùng hiện HTTP status/JSON. Không cần mở hoặc chạy hai bản cùng lúc.

Project demo hoàn chỉnh nằm riêng ở [Phan-3-Kien-Demo](../Phan-3-Kien-Demo/README.md).
